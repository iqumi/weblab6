# Список задач — лабораторная №7

**Автор:** Сергей <фамилия, отчество>, группа <номер группы>

To-Do на Vue 3 и Vite с регистрацией, входом, личными списками задач и страницей «О приложении».
Состояние хранится в Pinia (`useUserStore`, `useTodoStore`) и сохраняется в `localStorage`
через `pinia-plugin-persistedstate`. Страницы и ограничение доступа обеспечивает Vue Router
(режим `createWebHashHistory`, поэтому статическому хостингу не нужна настройка перенаправлений).

**Опубликованная версия:** <ссылка на GitHub Pages>

## Команды

```bash
npm install   # установка зависимостей
npm run dev   # запуск в режиме разработки
npm run build # production-сборка в dist/
```

## Учебная авторизация

Бэкенда нет: пользователи, пароли и состояние входа хранятся только в браузере и доступны
любому скрипту страницы. Механизм не защищает реальные данные. Для проверки используйте только
вымышленные email и учебные пароли, которые нигде больше не применяются.

## Порядок проверки

1. Откройте `#/todo` без входа — произойдёт перенаправление на страницу входа.
2. На странице регистрации проверьте ошибки: неверный формат email, разные пароли, повторный email.
3. Зарегистрируйте пользователя `first@example.com`, войдите, добавьте несколько задач.
4. Обновите страницу — вход и задачи сохраняются.
5. Нажмите «Выйти», зарегистрируйте и войдите как `second@example.com` — список пуст.
6. Выйдите и снова войдите как `first@example.com` — видны только его задачи.
7. Проверьте неверный пароль при входе и страницу «О приложении».
